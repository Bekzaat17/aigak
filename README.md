# Aigak

Помощник инспектора для проверки сайтов на признаки игорного бизнеса и подготовки материалов для ограничения доступа в Казахстане. Интерфейс и отчёты — на русском и казахском.

**Ссылка, файл или текст → анализ → проверка выводов инспектором → пакет документов.**

## Три уровня проверки

| Уровень         | Что делает                                                                                                                                                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Базовая**     | Без ИИ: сохраняет страницу и снимки, извлекает текст, ищет признаки по правилам, собирает DNS, RDAP, TLS и опубликованные контакты.                                                                                                |
| **Продвинутая** | Добавляет три AI-этапа: признаки, контекст и проверку выводов. Цитаты сверяются с сохранёнными источниками.                                                                                                                        |
| **Pro**         | Добавляет детектива, юриста и итоговую проверку полноты. Детектив ищет связанные ресурсы и сравнивает контакты, БИН и тексты. Юрист сопоставляет находки с сохранёнными официальными нормами РК и указывает недостающие основания. |

## Результат

- Понятный вывод, находки, цитаты, снимки и ссылки на исходные материалы.
- Карта связей ресурсов и правовые гипотезы с источниками.
- Вопросы инспектору, подтверждение или отклонение находок, добавление материалов и повторный анализ с историей версий.
- ZIP: DOCX RU/KK по встроенному или загруженному шаблону, стандартные PDF/HTML-отчёты, нумерованные приложения, оригиналы, журнал и контрольные суммы.

Сборка пакета — отдельный сервис. Проверки, AI-провайдеры и форматы документов заменяются независимо.

## Запуск

Нужны **Node.js 22.13+**, npm и Google Chrome.

```bash
npm ci
cp .env.example .env
npm run setup:ocr
npm run dev
```

Откройте [localhost:4317](http://localhost:4317). Данные хранятся локально в `data/`.

Для Продвинутой и Pro укажите `OPENAI_API_KEY` и `OPENAI_MODEL` в `.env`, затем перезапустите сервер. Другие модели и совместимые провайдеры подключаются через [AI Gateway](docs/AI_GATEWAY.md). Извлечённые тексты и материалы анализа передаются настроенному AI-провайдеру.

Если Chrome отсутствует, выполните `npx playwright install chromium` и удалите `BROWSER_CHANNEL=chrome` из `.env`.

```bash
npm run check    # стиль, архитектура, тесты, TypeScript и сборка
npm test         # только тесты
npm run format   # единое форматирование
npm start        # запуск собранного приложения
```

## Что учитывать

Это локальный однопользовательский MVP. Для общего доступа нужны авторизация и изоляция обработчиков.

Pro готовит **проект материалов**, а не решение о блокировке. Инспектор подтверждает факты, применимую редакцию закона и основания обращения. Совпадение IP или контактов само по себе не доказывает общего владельца. Поиск связей ограничен доступными источниками и бюджетом проверки.

Текущий реестр лицензий — исторический снимок; автоматический подбор редакции закона на дату события ещё не реализован. Недоступные источники и незавершённые этапы отображаются как ограничения. Качество реального AI-анализа требует проверки на экспертно размеченных делах.

Встроенный шаблон не является утверждённой формой ведомства. Пользовательский DOCX заполняется по полям шаблона; PDF и предпросмотр используют стандартное оформление.
