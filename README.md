# Aigak

Помощник инспектора для проверки сайтов на признаки игорного бизнеса и подготовки материалов для ограничения доступа в Казахстане. Интерфейс и отчёты — на русском и казахском.

**Ссылка на сайт → анализ → проверка выводов инспектором → пакет документов.**

В MVP новый анализ запускается по URL. Сбор, проверка качества страницы и привязка снимков к цитатам описаны в [правилах сбора](docs/COLLECTION.md).

## Состояние MVP на 15 октября 2026

Работает локальный продукт с постоянной историей дел, очередью PostgreSQL и отдельным
обработчиком. Pro использует оркестратор, стратегии браузерного доступа и независимую
проверку доказательств. Общий бюджет запуска — 15 минут по умолчанию (настраивается), а не обещание одинакового
времени для любого сайта. Успешные и неуспешные этапы сохраняются с длительностью,
использованной моделью и фактическими входными/выходными токенами, когда провайдер их вернул.

Сбой DNS, отказ соединения, ошибка HTTPS, тайм-аут, CAPTCHA и ошибка анализа имеют
разные объяснения. Недоступная страница не считается отсутствием игорных признаков.
Оценка ИИ в процентах относится к признакам предложения игры, не к незаконности сайта.

Юридический агент получает официальные тексты через публичный API «Әділет», проверяет
идентичность акта и извлекает конкретные статьи. При сбое предусмотрен HTML-источник.
Цитаты норм проверяются по сохранённому тексту. Казино, букмекерская деятельность и
лотерея различаются; название продукта само по себе не является правовой квалификацией.

Pro проверяет не только главную: опубликованные ссылки и карты сайта позволяют
обойти до 12 подстраниц в пределах трёх переходов. HTTP дополняется браузером.
Каждый адрес и результат доступа сохраняются. Пределы изменяются через
`AIGAK_SITE_PAGE_LIMIT`, `AIGAK_SITE_DEPTH`, `AIGAK_ANALYSIS_BUDGET_MS`.
При необходимости бюджет worker `PROCESSING_TIMEOUT_MS` также увеличивается.

После первого анализа доступные правила и документы сайта могут быть собраны
автоматически с повторной проверкой всех специалистов. История обоих проходов и
токены сохраняются; неполная перепроверка не выдаётся за новый подтверждённый вывод.
Юрист получает полный сохранённый текст применяемых норм, а содержательные агенты
не получают повторно весь правовой корпус и технический граф.

Готовность проекта пакета требует точной цитаты, URL и проверенного снимка каждой
принятой находки. Решение о блокировке, процессуальная допустимость и закрытые
обстоятельства не подменяются ответом модели. Экономия времени и точность на
независимой экспертной выборке пока не измерены.

## Три уровня проверки

| Уровень         | Что делает                                                                                                                                                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Базовая**     | Без ИИ: сохраняет страницу и снимки, извлекает текст, ищет признаки по правилам, собирает DNS, RDAP, TLS и опубликованные контакты.                                                                                                |
| **Продвинутая** | Добавляет три AI-этапа: признаки, контекст и проверку выводов. Цитаты сверяются с сохранёнными источниками.                                                                                                                        |
| **Pro**         | Добавляет детектива, юриста и итоговую проверку полноты. Детектив ищет связанные ресурсы и сравнивает контакты, БИН и тексты. Юрист сопоставляет находки с сохранёнными официальными нормами РК и указывает недостающие основания. |

## Результат

- Понятный вывод, находки, цитаты, снимки и ссылки на исходные материалы.
- Карта связей ресурсов и правовые гипотезы с источниками.
- Вопросы инспектору, подтверждение или отклонение находок, добавление материалов и повторный анализ с историей версий.
- ZIP: DOCX RU/KK по встроенному или загруженному шаблону, стандартные PDF/HTML-отчёты, нумерованные приложения, оригиналы, журнал и контрольные суммы.

Сборка пакета — отдельный сервис. Проверки, AI-провайдеры и форматы документов заменяются независимо.

В основных материалах — только подтверждённые снимки конкретных находок и тексты с
точными цитатами. Страницы защиты, технические ответы и старые снимки доступны в архиве.
Каждое дело открывается по постоянной локальной ссылке без повторного анализа; приложение
и его хранилище должны оставаться доступными.

## OSINT и связи

- Публичные контакты, заявленная организация, БИН и лицензия: отдельные наблюдения с источником.
- Регистрация: RDAP и официальный WHOIS KazNIC для .kz/.қаз; даты регистрации,
  изменения и истечения, регистратор и опубликованная организация-регистрант.
- История Pro: запросы к Wayback Machine для трёх прошлых дат и имена из журнала
  сертификатов. Сохраняются ответы, даты и ссылки; это выборка, не полная история сайта.
- Соцсети и публичные каналы показаны отдельно от связанных сайтов.
- Связанные сайты: опубликованные поддомены, совпадения контактов/БИН и кандидаты
  на копию по сходству текста. Обычная внешняя ссылка и общий IP не означают зеркало.

Скрытые сведения о регистранте не восстанавливаются. Архивная ссылка не доказывает
нынешнее содержание сайта; статус резервного сайта или зеркала требует подтверждения.
Описание контрактов и ограничений: [расширенный OSINT](docs/DEEP_OSINT.md).

## Запуск одной командой

Нужен запущенный **Docker с Compose**:

```sh
./scripts/up.sh
```

Команда создаёт `.env`, если его ещё нет, собирает приложение с Chromium и OCR, запускает PostgreSQL, применяет миграции и поднимает API и отдельный worker. Откройте [localhost:4317](http://localhost:4317). Первая сборка требует времени на загрузку зависимостей.

Записи дел и очередь хранятся в PostgreSQL; оригиналы и шаблоны — в `data/`. Существующий `.env` и материалы сохраняются. Перенос прежней SQLite выполняется явно по [руководству PostgreSQL](docs/POSTGRESQL.md).

Команды обслуживания, восстановление задач и запуск для разработки: [Очередь и Docker](docs/QUEUE_AND_DOCKER.md).

Для Продвинутой и Pro укажите `OPENAI_API_KEY` и `OPENAI_MODEL` в `.env`, затем повторите `./scripts/up.sh`. Другие модели и совместимые провайдеры подключаются через [AI Gateway](docs/AI_GATEWAY.md). Извлечённые тексты и материалы анализа передаются настроенному AI-провайдеру.

Для разработки без контейнеров: если Chrome отсутствует, выполните `npx playwright install chromium` и удалите `BROWSER_CHANNEL=chrome` из `.env`.

```bash
npm run check    # стиль, архитектура, тесты, TypeScript и сборка
npm test         # только тесты
npm run format   # единое форматирование
npm start        # запуск собранного приложения
```

## Что учитывать

Это локальный однопользовательский MVP. Для общего доступа нужны авторизация и изоляция обработчиков.

Pro готовит **проект материалов**, а не решение о блокировке. Инспектор подтверждает факты, применимую редакцию закона и основания обращения. Совпадение IP или контактов само по себе не доказывает общего владельца. Поиск связей ограничен доступными источниками и бюджетом проверки.

Текущий реестр лицензий — исторический снимок; автоматический подбор редакции закона на дату события ещё не реализован. Недоступные источники и незавершённые этапы отображаются как ограничения. Качество реального AI-анализа требует проверки на экспертно размеченных делах.

Встроенный шаблон не является утверждённой формой ведомства. Пользовательский DOCX заполняется по полям шаблона; PDF и предпросмотр используют стандартное оформление.
