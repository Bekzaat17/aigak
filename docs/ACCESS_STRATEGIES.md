# Доступ к защищённым сайтам

Успех доступа — загрузка читаемого целевого содержимого после исчезновения преграды.
Нажатие флажка, ответ HTTP 200 и получение cookie сами по себе не доказывают успех.
Снимок CAPTCHA — свидетельство ограничения доступа, а не доказательство нарушения сайта.

## Подключённые способы

- HTTP, обычный Chromium и мобильный Chromium.
- Patchright 1.64.0 (Apache-2.0), отдельная резервная стратегия через общий контракт браузерной сессии.
- Обработчик Cloudflare: ограниченное ожидание автоматической проверки, взаимодействие с видимым checkbox в официальном iframe, подтверждение загрузки содержимого.
- Сетевой адаптер разрешает не более 16 служебных POST размером до 256 KiB по пути `/cdn-cgi/challenge-platform/` на исходном origin или `challenges.cloudflare.com`. Остальные ограничения запросов, публичных адресов и отмены сохраняются.
- История сохраняет длительность, результат и `CAPTCHA_REQUIRED`, если доступ не подтверждён. Никакого выдуманного успешного прохождения.

## Матрица расширения

| Препятствие                           | Текущее поведение                                  | Следующий отдельный адаптер / проверка                                |
| ------------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------- |
| Cloudflare JS / Turnstile checkbox    | Обычный браузер → Patchright → проверка результата | SeleniumBase CDP, сравнить на реальных страницах                      |
| reCAPTCHA / hCaptcha: картинки, аудио | Автоматическое решение пока не реализовано         | Отдельный solver с контрактом результата, отменой и учётом расходов   |
| Блокировка IP / HTTP 403              | Сохранение ограничения, смена браузера             | Настроенный провайдер сети; наличие другой сети не гарантирует доступ |
| Географическое ограничение            | Нельзя считать CAPTCHA или отсутствием признаков   | Разрешённая точка наблюдения с указанием страны в доказательстве      |
| HTTP 429                              | Ограниченный бюджет; не бесконечные повторы        | Повтор по Retry-After в пределах бюджета                              |
| DNS / TLS / тайм-аут                  | Отдельная причина неуспеха                         | Альтернативный транспорт без отключения проверки TLS                  |
| Авторизация                           | Отдельный сценарий login / register и OTP          | Расширение проверенных профилей форм                                  |
| KYC, документ, телефон                | Автоматическое завершение не реализовано           | Участие инспектора и разрешённая учётная запись                       |

## Проверенные источники решений

- Patchright Node.js: https://github.com/Kaliiiiiiiiii-Vinyzu/patchright-nodejs
- SeleniumBase + Playwright: https://seleniumbase.github.io/examples/cdp_mode/playwright/ReadMe/
- FlareSolverr: https://github.com/FlareSolverr/FlareSolverr
- playwright-captcha: https://github.com/techinz/playwright-captcha

Открытый исходный код не означает, что все режимы работают без внешнего платного сервиса.
FlareSolverr не следует представлять универсальным решателем CAPTCHA.
Поддержку новой защиты подтверждаем реальным прогоном и сохраняем результат отдельно
от синтетических тестов. Нельзя заявлять обход всех CAPTCHA или всех сайтов.

## Реализация для sz.kz

Резервный браузер использует отдельный временный persistent profile Patchright.
На сервере worker запускается с Xvfb; пользовательский профиль Chrome не используется.
После подтверждённой страницы Cloudflare допускаются максимум два завершающих
POST на тот же адрес с формой проверки. Разрешение отзывается при завершении этапа.
Для публичной страницы sz.kz отдельно зарегистрирована ограниченная отправка
технических данных `/api/fl` (4 запроса, до 16 KiB каждый); регистрация и платежи
этим правилом не разрешаются. Значения технических данных в отчёт не попадают.
Контрольный прогон на macOS 15.10.2026 получил целевой текст Mega Casino примерно
через 5 секунд проверки. Это проверка конкретной площадки и окружения, не гарантия
для всех сетей, версий Cloudflare и CAPTCHA.
