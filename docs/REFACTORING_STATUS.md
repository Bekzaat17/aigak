## Что сделано 14 октября

- `Store` превращён в фасад зависимостей. SQL, файлы, метаданные материалов, аудит и проверка целостности разделены между `SqliteCaseRepository`, `FileBlobStorage`, `EvidenceService`, `AuditLog` и `CaseIntegrityVerifier`.

- Локальные адаптеры собираются только в `createLocalStorage`; соединение и его закрытие принадлежат фабрике/владельцу контекста. Изменения внутренних сигнатур описаны в архитектуре.
- URL и контактные страницы используют готовый `EvidenceExtractor`; OCR больше не создаётся заново для каждого такого файла. Сборка `exportCase` вынесена в bootstrap и принимает каталог явно.
- Добавлены контрактные тесты файлового/подставного адаптера, подмены зависимостей каталога и сервисов, отказа записи, целостности и чтения базы прежнего формата без перезаписи JSON.
- Добавлен повторяемый браузерный сценарий `npm run test:ui`; завершена вчерашняя проверка интерфейса.
