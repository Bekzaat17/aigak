# Рефакторинг: точка остановки

Дата: 13 октября 2026 года. Работа остановлена по просьбе владельца; следующий этап продолжается с этого состояния.

## Обязательное требование

Строго соблюдать SOLID. Правила для последующих изменений: [AGENTS.md](../AGENTS.md). Карта модулей и направление зависимостей: [ARCHITECTURE.md](ARCHITECTURE.md).

## Что сделано

- Серверный запуск и сборка зависимостей вынесены в `server/bootstrap`; HTTP-приложение создаётся отдельно и принимает зависимости.
- HTTP-маршруты разделены по областям. Команды приёма, дополнения материалов и проверки вынесены в `server/application`.
- Очередь отделена от процессора и этапов обработки. Добавлены порты хранения, журналирования, заданий, шаблонов и документов; зависимости этапов сужены до используемых методов.
- Классы проверок, стратегий, AI/OSINT/документных адаптеров находятся в отдельных именованных файлах.
- Извлечение текста поддерживает регистрацию реализаций `FileExtractor`; OCR подключается через `OcrEngine`.
- AI-промпты разнесены по задачам в `server/ai/prompts`; тексты и версии сохранены.
- React entry point и основной компонент разделены. Выделены экраны, компоненты редакторов, hooks, API-клиент, словари и форматирование.
- Добавлены Prettier, ESLint, EditorConfig, проверка архитектурных границ и GitHub Actions. Единая команда — `npm run check`.
- Старые точки импорта оставлены для совместимости. Формат базы и сохранённых материалов не менялся.

## Проверено

`npm run check` полностью прошёл: форматирование, ESLint, архитектура, **90 тестов**, TypeScript и production-сборка.

Пять новых тестов покрывают последовательность очереди, заменяемые этапы и сохранение материалов при сбое, подключение нового извлекателя, контракт стратегий и HTTP API с подставными зависимостями. HTTP-тест проверяет Host/Origin, приём, правки, повторный анализ, документы и предпросмотр.

Браузерная проверка на временной базе дошла до демонстрационного анализа: отображались 15 находок, ошибок JavaScript не было. Дальнейшая проверка остановилась на неверном селекторе тестового сценария: он искал `/Пакет/`, а кнопка называется «Проверка и пакет». Это не подтверждённая ошибка приложения. Вкладка пакета, RU/KK, панель истории и мобильное отображение в этом браузерном прогоне остались непроверенными.

Реальные AI-запросы, OCR моделей и сетевой сбор внешних сайтов после рефакторинга не запускались. Пользовательские данные в `data/` не изменялись.

## С чего продолжить

1. Завершить браузерную проверку: демонстрация → «Проверка и пакет» → предпросмотр; затем RU/KK, история/Escape, мобильный экран, решения по находкам и добавление материалов. Использовать временный `DATA_DIR`, не реальные дела.
2. Провести дополнительное ревью ответственности модулей. Приоритет: `server/storage/Store.ts` ещё объединяет SQL, файлы и целостность; `Templates.ts` — хранение и валидацию DOCX. Выделить отдельные адаптеры с контрактами и тестами.
3. Проверить оставшуюся координацию в `src/app/useAppController.ts`, размер `CaseScreen.tsx` и локальное состояние редакторов. Декомпозировать только по ответственности, сохранив пользовательский сценарий.
4. Проверить инфраструктурные обёртки совместимости (`collector.ts`, `extractFile`, `exportCase`) и постепенно переводить внутренние вызовы на собранные зависимости. Удалять старые пути только после проверки всех потребителей.
5. Усилить контрактные тесты OCR, хранилища и отмены внешних адаптеров. Статический запрет циклов и неправильных импортов не доказывает полное соблюдение всех принципов SOLID.

Рефакторинг существенно продвинут, но **полный архитектурный аудит не объявлен завершённым**. Новую функциональность, изменение бизнес-правил и переписывание продуктовых сценариев в этот этап не включали.
