# Сценарии и агенты Aigak Pro

Инспектор выбирает URL и разрешённый сценарий. Оркестратор управляет исполнителями;
результат сборщика проверяется отдельно. Каждому AI-анализу назначены роль, навык,
обязанности, инструменты, формат результата, критерии завершения и ограничения
в `server/ai/prompts/agent-roles.ts`. Браузерный агент имеет отдельный промпт.

## Ответственность

| Роль                | Исполнитель              | Обязанность                                                       |
| ------------------- | ------------------------ | ----------------------------------------------------------------- |
| Оркестратор         | CaseProcessingService    | Стадии, общий дедлайн, журнал, контрольные точки                  |
| Сбор                | CollectionOrchestrator   | Изолированные параллельные стратегии и запасные волны             |
| Проверка сбора      | CollectionReviewer       | Принимать результат по содержимому, независимо от сборщика        |
| Браузерный агент    | StagehandControlObserver | Найти реальные видимые элементы без получения паролей             |
| Доступ              | AuthenticationStage      | Только разрешённый вход/регистрация и подтверждение сессии        |
| Контекст            | context                  | Отличить предложение от новости, цитаты или профилактики          |
| Механика            | mechanics                | Подтвердить ставки, шанс, призы и приглашение точными цитатами    |
| Проверка содержания | verification             | Перепроверить кандидатов по первичным материалам                  |
| Закон               | legal                    | Указать акт, статью, источник, применимость и недостающие условия |
| Итоговая проверка   | pro_review               | Проверить согласованность, атрибуцию и пробелы                    |
| Доказательства      | EvidenceSupervisor       | Цитата, снимок, авторизация, запасной способ проверки             |

Роль не обязательно является LLM-вызовом. Проверка хеша, точной цитаты, домена,
дедлайна и разрешённого действия выполняется кодом. Согласие нескольких моделей
не считается независимым доказательством, вероятности специалистов не усредняются.

## Оркестрация

Общий дедлайн Pro — 400 секунд. Бюджеты: сбор 130 секунд, авторизация 60,
паспорт ресурса 15, нормы закона 30, обогащение 20, анализ 90, доказательства 50. Неиспользуемые
сценарии пропускаются. Возобновление сохраняет исходный дедлайн. Сохранение данных
и закрытие ресурсов завершаются отдельно от отменяемых сетевых действий.

CollectionOrchestrator запускает не более двух сборщиков одновременно. Каждый
получает копию дела и ограниченное хранилище памяти. Только оркестратор записывает
их результаты в дело последовательно, переназначая связи между материалами.
Недостаточный сбор запускает запасную волну. Повторять одну ошибку бесконечно нельзя.

ScopedCaseStore запрещает поздние записи отменённой стадии. Рабочая копия отделена
от итогового дела: зависший провайдер не перезапишет готовый отчёт после таймаута.
При исчерпании бюджета остаётся частичный результат, а не фиктивный успех.

## Браузер и доступ

Stagehand 4.2.1 получает копию видимых элементов без значений полей, cookies и
сессионных токенов. Он предлагает элемент; исполнитель проверяет исходный DOM.
Публичный агент переходит только по информационным ссылкам того же сайта, без
произвольных кликов, платежей, ставок и изменений профиля.

Настроенные профили поддерживают вход и регистрацию. Если селектор изменился,
Stagehand может найти элемент по описанию до заполнения всех полей.
Автоматическая регистрация обнаруживает форму email/password и создаёт выделенный
ящик через [Mail.tm](https://mail.tm). Ссылка подтверждения проверяется по домену
и назначению. После нормального завершения ящик удаляется. При повторном запуске
того же дела регистрация не дублируется.

Одноразовый код инспектор вводит в открытом деле; агент продолжает ту же сессию.
FileAuthChallenges передаёт код между API и worker через закрытые временные файлы.
Код не включается в дело, промпты и экспорт; файлы очищаются после получения,
отмены или истечения 45 секунд.

## Проверка и история

EvidenceSupervisor проверяет связь цитаты с материалом и пробует другой браузерный
способ, если снимок не подтверждён. Закрытая находка требует действующей сессии.
Неподтверждённый снимок не подставляется в находку. Отсутствие доступа не превращается
в отсутствие признаков или вероятность 0%. Юридическая гипотеза требует точной
ссылки на сохранённую норму и подтверждённых фактов.

scenarioRun сохраняет решения, длительность и фактические токены Stagehand,
включается в ревизии и экспорт. Неизвестная цена обозначается как неизвестная.
Основные выводы отделены от технического журнала.

## Ограничения

Автоматическая регистрация поддерживает формы email/password. Обязательные
персональные данные, телефон, документы и неподдерживаемые формы не заполняются
выдуманными значениями. CAPTCHA автоматически не обходится. Нет гарантии входа
на произвольный сайт, особенно при внешней сетевой блокировке: Stagehand не меняет IP.

Проверка снимка основана на точной видимой цитате до/после захвата, а не на независимой
экспертной интерпретации изображения. Браузерные тесты используют синтетические
источники; реальные проверки сохраняются отдельно через приложение.
